## Was habe ich gemacht?
Diese Woche habe ich gleich drei grosse Themen angegangen. Zuerst habe ich Terraform als Infrastructure as Code Tool eingeführt und einen Multi-Cloud Ansatz mit AWS und Azure umgesetzt – eine `main.tf` beschreibt gleichzeitig Ressourcen auf beiden Clouds. Danach habe ich drei Sicherheitskonzepte implementiert: Kubernetes Secrets für den API Key, eine Network Policy zur Absicherung der Pod-Kommunikation und HTTPS mit einem self-signed Zertifikat über einen Nginx Ingress Controller.

## Was habe ich gelernt?
Mit Terraform wird Infrastruktur nicht mehr manuell in der Cloud-Konsole erstellt sondern als Code in `.tf`-Dateien beschrieben. Terraform unterstützt mehrere Cloud-Provider gleichzeitig – das nennt sich Multi-Cloud. Kubernetes Secrets speichern sensitive Daten wie API Keys verschlüsselt im Cluster und können als Umgebungsvariablen in Pods eingebunden werden. Network Policies funktionieren wie eine Firewall innerhalb des Clusters. HTTPS wird über einen Ingress Controller mit TLS-Zertifikat realisiert.

## Was war schwierig?
