# Woche 4

- Docker auf der EC2 Instance installieren und ein Dockerfile für das Backend erstellen.

- Docker auf EC2 installiert
- Dockerfile für Backend und Frontend erstellt
- Docker Images gebaut und Container gestartet
- docker-compose.yml erstellt um beide Container mit einem Befehl zu steuern

- EBS Volume von 8GB auf 20GB vergrössert

- Kubernetes Deployment Files für Backend und Frontend erstellt

- Projektplanung, Netzwerkdokumentation und Docker-Dokumentation geschrieben

## Welche Schwierigkeiten hatte ich?

| Problem | Ursache | Lösung |
|---------|---------|--------|
| Dashboard zeigte "Laden..." | Alte IP hardcodiert im Frontend | IP mit `sed` ersetzt |
| Backend Container crashte | `flask-cors` fehlte in requirements.txt | Modul nachgetragen, Image neu gebaut |
| `docker-compose` not found | Neuere Docker-Version | `docker compose` ohne Bindestrich verwenden |
| GitHub Push abgelehnt (403) | Token abgelaufen | Neuen PAT mit `repo` und `workflow` Scope erstellt |
| Workflow YAML Fehler | Falsche Einrückung bei `script` | YAML Syntax korrigiert |
| Kein Speicherplatz für Minikube | EBS Volume zu klein (8GB) | Volume auf 20GB vergrössert |
| HPA zeigte `<unknown>` | Keine CPU-Limits in Deployment definiert | `resources.requests` und `limits` in YAML ergänzt |
