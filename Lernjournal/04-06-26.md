# Woche 3

## Ziele für Woche 3 in Woche 2 geschrieben


- Backend aufsetzen – Eine einfache Python Flask API erstellen, die Daten von der football-data.org API abruft und als JSON zurückgibt.
- Docker-Image erstellen – Die Flask App in ein Docker-Image verpacken und lokal zum Laufen bringen.
- Frontend erstellen – Eine einfache HTML-Seite bauen, die die Daten vom Backend anzeigt.


## Was habe ich gemacht?
Ich habe eine EC2 Instance auf AWS Academy Learner Lab erstellt und mich per SSH verbunden. Anschliessend habe ich das GitHub Repository auf die Instance geklont und die Projektstruktur eingerichtet. Ich habe das Backend mit Python Flask aufgesetzt, welches Daten von der football-data.org API abruft und als JSON zurückgibt. Danach habe ich ein einfaches HTML Frontend erstellt, das die Premier League Tabelle übersichtlich anzeigt. Am Ende war die komplette Web-App über die öffentliche IP der EC2 Instance im Browser erreichbar.

## Was habe ich gelernt?
Ich habe gelernt wie man eine EC2 Instance in AWS erstellt und konfiguriert. Ausserdem habe ich verstanden wie eine Flask API funktioniert und wie man externe APIs einbindet. Ich habe das CORS-Konzept kennengelernt – der Browser blockiert standardmässig Anfragen zwischen verschiedenen Ports, was ich mit flask-cors gelöst habe. Zudem habe ich gelernt wie man GitHub mit einem Personal Access Token authentifiziert.

## Was war schwierig?
Die Authentifizierung mit GitHub hat anfangs nicht funktioniert, weil das normale Passwort nicht mehr unterstützt wird und das Repository auf privat gestellt war. Ausserdem hat die Tabelle im Frontend zuerst keine Daten angezeigt wegen dem CORS-Problem.

## Wie habe ich es gelöst?
Für GitHub habe ich einen Personal Access Token erstellt und das Repository auf public gestellt. Das CORS-Problem habe ich gelöst indem ich flask-cors installiert und in der app.py eingebunden habe.

## Zielerreichung

- Frontend erstellt – HTML-Seite zeigt die Premier League Tabelle an
- Docker-Image erstellt – verschoben auf Woche 3
